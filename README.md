# Poseidon

**A maritime investigation workspace for reviewing vessel activity near Marine Protected Areas (MPAs).**

Poseidon brings Global Fishing Watch event data, public-source research, vessel details, and an agent investigation trail into one place. It helps reviewers decide which cases deserve a closer look and presents the evidence and its limitations in a cited brief.

Every case is a **lead flagged for review, not proof of illegal activity**. AIS gaps do not show where a vessel travelled while its signal was absent. The globe displays recorded observations from the loaded dataset; it is not a live vessel-position feed.

## Open Poseidon in VS Code

The quickest way to open the app you can demo is to run `python-app/app.py` from VS Code.

### One-time setup

Open the repository folder in VS Code. In the VS Code terminal, install the Python app's dependencies:

```bash
python -m pip install -r python-app/requirements.txt
```

### Each time you want to open it

1. In VS Code's Explorer, open `python-app/app.py`.
2. Click **Run Python File** in the top-right corner of the editor.
3. In the terminal, find the address printed after `Poseidon Python App listening on` and open it in your browser. By default, it is [http://127.0.0.1:8000](http://127.0.0.1:8000).

Leave the Python process running while you use the app. To close it, focus the terminal and press **Ctrl+C**. The app can browse the included snapshot without API keys.

To use another port, set the `PORT` environment variable before running `app.py`.

## What you can explore

- Browse published vessel cases and protected areas on an interactive globe.
- Review event timelines, vessel identity, risk-score reasons, cited sources, and investigation notes.
- Explore news and area context included with the publication.
- Open the historical replay from **About**.
- Review the snapshot's publication time, observation window, and data notes.

The app reads a published JSON snapshot, so opening it locally does not fetch fresh vessel observations. Local investigations can use evidence already in the snapshot; fresh data and research require the relevant credentials and services.

## How it works

The Databricks notebook collects and investigates cases, then publishes a JSON snapshot for the website. The web app reads that snapshot and displays its evidence. During an investigation, the agent can choose from permitted checks; Python executes the selected tool, records the result, and calculates the score. The final brief includes sources, caveats, and missing information.

```text
Global Fishing Watch + public sources
                 ↓
       Databricks notebook
                 ↓
 Cases, investigation trace, cited brief
                 ↓
         JSON publication
                 ↓
        Poseidon web app
```

Risk scores are calculated by code, not generated by the model. Case status describes investigation progress, not whether a vessel complied with the law. When a model is unavailable, the backend can use a rule-based policy.

The VS Code steps above run the Python app. The repository also includes a Node-hosted version for Databricks; its deployment settings are in [`app.yaml`](app.yaml).

## Connect a Databricks deployment

The local app is useful for browsing the included publication. To connect it to Databricks, deploy the root app using [`app.yaml`](app.yaml), attach the export volume as the `poseidon-exports` resource, and configure the required Databricks app identity and permissions. To enable on-demand investigations, attach the dedicated investigation job and enable the corresponding `POSEIDON_JOB_ID` resource binding in `app.yaml`.

See [`app/README.md`](app/README.md) for the app workflow and [`deploy/`](deploy/) for job definitions. The Databricks notebook and backend use credentials stored in Databricks; do not put API keys in browser code or commit them to Git.

## Development

Run the JavaScript test suite from the repository root:

```bash
npm test
```

The Python backend tests can be run with:

```bash
python -m unittest discover -s tests -v
```

The tests use local fixtures and mocks. They do not verify access to a live Databricks workspace or external data providers.

## Data attribution and limits

Poseidon uses data from [Global Fishing Watch](https://globalfishingwatch.org/). Follow the applicable API and dataset terms, including attribution and non-commercial-use restrictions. Preserve source links and the “lead flagged for review” disclaimer when reusing the interface or its reports.

AIS coverage, vessel identity records, and event classifications can be incomplete. Public reporting can refer to later events or similarly named vessels. Review the linked evidence and the case's caveats before drawing conclusions.
